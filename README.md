# Portfolio de Sofía Rodríguez Sutil

Implementación estática y responsive del diseño original de Figma. No necesita
instalar dependencias ni ejecutar un proceso de compilación.

## Vista local

Desde la raíz del repositorio:

```bash
python3 -m http.server 4173
```

Después abre [http://localhost:4173](http://localhost:4173).

## Estructura

- `index.html`: contenido y composición de la página.
- `styles.css`: reproducción del lienzo de escritorio y adaptación móvil.
- `script.js`: escala intermedia, navegación interna y scroll suave.
- `assets/`: imágenes y vídeos optimizados a partir de los recursos del diseño.
